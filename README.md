# Tamid Lahapsid (Fabric, Minecraft 1.21.4)

Build (JDK 21 + Gradle 8.12+):  gradle build   -> build/libs/tamidlahapsid-1.0.0.jar
Or push to GitHub: the Actions workflow builds the jar for you.

Install: Modrinth App -> Fabric 1.21.4 profile -> Fabric API + this jar.
Open GUI: Right Shift (changeable in Visuals). Drag the title bar to move the window.
